# ADR-012: Work-log obligatorio por sesión

## Contexto

En la sesión de consolidación (85+ commits, 8+ horas) no se creó ningún work-log. El SKILL decía "document in work-logs/ if needed" — el "if needed" lo hacía opcional y nunca se hacía.

Esto fue documentado como ERR-021.

## Decisión

Cada sesión de trabajo DEBE tener un work-log en `context/work-logs/YYYY-MM-DD-HH-MM-desc.md`.

El work-log no es un artefacto de fase — es un artefacto de SESIÓN:
- Se CREA al iniciar la sesión
- Se ACTUALIZA durante Phase 6 (progreso)
- Se CIERRA al finalizar (Phase 7)

## Alternativas consideradas

- **Opcional ("if needed"):** Lo que teníamos. Rechazado porque "if needed" = nunca en la práctica.
- **Solo para sesiones largas (>2h):** Razonable pero difícil de medir. Rechazado por ambigüedad.
- **Obligatorio siempre:** Simple, claro, sin excusas.

## Consecuencias

- CLAUDE.md "Flujo de sesión" actualizado: paso 1 incluye crear work-log
- SKILL.md Phase 6 cambiado de "if long session" a siempre
- SKILL.md tiene nueva sección "Session Artifacts" que define cuándo crear work-logs, ADRs, y epics
- Próxima sesión que no tenga work-log es un error documentable
