Patrón: undeclared-passthrough-settings-field-indexed
Señal del verificador: : TS7053: Element implicitly has an 'any' type because expression of type 'string' can't be used to index type '\{\}'\.
Arreglo genérico: El campo viene de `SettingsJson`/`Settings`, cuyo schema usa `.passthrough()`: las claves no declaradas en el `z.object({...})` (p. ej. `extraKnownMarketplaces`, que `settings/inventory.ts` documenta explícitamente como fuera del shape) no tienen tipo indexable, aunque en runtime sí son un mapa por clave. Se afirma esa forma real con un `as Record<string, V> | undefined` una sola vez, en una constante local, y se indexa esa constante en vez de repetir el acceso a la propiedad del objeto original.
