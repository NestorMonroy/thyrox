Patrón: repeated-index-access-not-narrowed
Señal del verificador: TS2532: Object is possibly 'undefined'
Arreglo genérico: Cuando `noUncheckedIndexedAccess` produce un error tras un patrón `if (!obj[key]) obj[key] = ...; obj[key].foo`, capturar el valor en una variable local (`let entry = obj[key]; if (!entry) { entry = ...; obj[key] = entry }; entry.foo`) para que TS angoste sobre la variable en vez de repetir el acceso indexado, sin cambiar la conducta.
