Patrón: unknown-attachment-field-needs-local-shape
Señal del verificador: TS18046: '\w+' is of type 'unknown'|TS7006: Parameter '\w+' implicitly has an 'any' type
Arreglo genérico: El campo `attachment` de AttachmentMessage es `{ type: string; [key: string]: unknown }`, así que cualquier propiedad distinta de `type` llega como `unknown`. Tras descartar la rama `string` con `typeof`, castear explícitamente al shape mínimo que el código ya asume (p. ej. `Array<{ type: string; text?: string }>`), replicando el patrón ya usado en `transcriptSearch.ts:99` para el mismo campo `prompt`. No usar `any`/`as unknown as`.
