Patrón: object-literal-widened-string-instead-of-literal-type
Señal del verificador: TS2769: No overload matches this call\.|is not assignable to type '"[A-Za-z]+"'
Arreglo genérico: Cuando un objeto literal const se compara con toEqual/toMatchObject contra un tipo cuyo campo discriminante es un literal string (p. ej. "safetyCheck"), TypeScript infiere ese campo como `string` genérico salvo que se le fuerce el tipo. Se le añade `as const` al literal (o se anota con el tipo exportado del módulo, p. ej. `: SafetyDecisionReason`) para que el campo quede como literal y no como `string` ancho — sin tocar el valor en tiempo de ejecución.
