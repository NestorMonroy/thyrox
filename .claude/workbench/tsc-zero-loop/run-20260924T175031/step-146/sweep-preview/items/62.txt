Patrón: optional-field-passed-to-required-param
Señal del verificador: TS2345.*'string \| undefined' is not assignable to parameter of type 'string'
Arreglo genérico: Cuando un campo opcional (p. ej. `headCommit?: string` de `createAgentWorktree`) se pasa a un parámetro que lo exige requerido (`hasWorktreeChanges(worktreePath: string, headCommit: string)`), no se afirma con `!` ni se castea: se añade una guarda `if (!campo) { ... return/continue }` antes de la llamada, replicando el patrón ya establecido en `AgentTool.tsx` para el mismo caso (`if (headCommit) { ... }`), que trata la ausencia como 'sin verificar, conservar'.
