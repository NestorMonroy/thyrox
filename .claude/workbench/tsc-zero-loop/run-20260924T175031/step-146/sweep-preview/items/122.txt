Patrón: deferred-passthrough-settings-key-is-unknown
Señal del verificador: TS2322: Type 'unknown' is not assignable to type '(string \| undefined|[^']*\[\] \| null)'
Arreglo genérico: Cuando una clave de settings está marcada como "diferida" en inventory.ts (no declarada en SettingsSchema de types.ts), leerla desde el objeto que devuelve getSettingsForSource() produce `unknown` por el `.passthrough()` del esquema. Se corrige acotando el tipo del objeto leído con un cast local a la forma conocida de esa clave (p. ej. `as { campo?: Tipo } | null`), igual que ya hace settings.ts en otros puntos (`as { autoMode?: unknown } | null`) — nunca con `any`/`as unknown as`.
Ya aplicado en: src/packages/config/plugin/marketplaceHelpers.ts
Archivos donde la señal sigue viva: src/packages/agent/task/framework.ts, src/packages/repl/src/components/Message.tsx, src/packages/repl/src/queryHelpers.ts
