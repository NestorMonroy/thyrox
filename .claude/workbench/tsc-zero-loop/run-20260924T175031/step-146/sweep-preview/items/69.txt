Patrón: cast-que-debilita-narrowing-de-union-discriminada
Señal del verificador: TS2345.*is not assignable to parameter of type.*index: number, array:
Arreglo genérico: Cuando un valor ya viene de una función que devuelve una unión discriminada (p. ej. `{ eligible: false; errors: T[] }`), y el `if` ya narrowea sobre el discriminante, un `as { ...; errors: Array<{ type: string }> }` sobre ese valor sustituye el tipo real por uno más débil que TS infiere solo. La causa se corrige quitando el cast: el narrowing del `if` ya deja el tipo correcto sin ayuda.
