Patrón: implicit-any-callback-on-loosely-typed-host-binding
Señal del verificador: TS7006:.*[Pp]arameter '\w+' implicitly has an 'any' type
Arreglo genérico: Cuando un valor deriva de un binding de host tipado deliberadamente como `(...args: any[]) => any` (los stubs de `appRuntime.ts`), su tipo real se pierde y cualquier callback que reciba (`.filter`, `.map`, o el propio binding invocado con una función) termina con parámetros implícitamente `any`. Se anota explícitamente el tipo en el primer punto donde el valor entra a código tipado — la variable intermedia (`const x: T[] = ...`) o el parámetro del callback (`(current: Record<string, unknown>) => ...`) — nunca el archivo de bindings, que es laxo a propósito.
Ya aplicado en: src/packages/swarm/src/worktree/index.ts
Archivos donde la señal sigue viva: src/packages/agent/hooks.ts, src/packages/cli/src/headless/sdk/session/run-streaming.ts, src/packages/repl/src/commands/color/color.ts
