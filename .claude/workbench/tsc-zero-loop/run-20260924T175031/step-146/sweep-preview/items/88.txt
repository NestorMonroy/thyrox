Patrón: renderable-message-switch-missing-progress-case
Señal del verificador: : TS2366: Function lacks ending return statement and return type does not include 'undefined'\.
Arreglo genérico: RenderableMessage incluye la variante `{ type: 'progress' }` aunque NAVIGABLE_TYPES (y análogos) sólo listan seis tipos. Un switch sobre `msg.type` que no declara `case 'progress'` deja de ser exhaustivo bajo strictNullChecks y TS marca la función como sin retorno final. Se añade el case explícito con el valor que corresponde a «no accionable / sin texto» (`false`, `''`, etc.), sin tocar los demás casos.
