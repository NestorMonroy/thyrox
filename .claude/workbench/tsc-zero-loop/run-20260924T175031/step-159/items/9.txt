Patrón: explicit-callback-param-type-mismatch
Señal del verificador: TS2769: No overload matches this call
Arreglo genérico: Cuando el callback de .filter/.map/.find lleva una anotación de tipo explícita importada que no coincide con el tipo real del elemento del array (el array tiene un tipo inline propio, distinto del tipo importado), se retira la anotación del parámetro y se deja que TypeScript infiera el tipo por contexto desde el array; si el tipo importado queda sin otro uso en el archivo, se retira también del import.

Archivos donde la señal sigue viva: src/packages/agent/QueryEngine.ts, src/packages/app-host/src/runtime/commandRegistryRuntime.ts
