Señal del verificador: TS2345: Argument of type 'string' is not assignable to parameter of type '\`\$\{string\}-\$\{string\}-\$\{string\}-\$\{string\}-\$\{string\}\`'
Arreglo genérico: El campo `uuid` de un mensaje SDK está inferido de un esquema zod (`z.string()` vía `UUIDPlaceholder`), así que tipa como `string`, mientras que el consumidor (un `Set<UUID>`, una función de storage) exige el `UUID` de `node:crypto` (plantilla literal). Se afirma con `as UUID` en el sitio de uso — igual que ya hace el mismo archivo para `sessionId`/`user_message_id` — porque el productor del valor ya garantiza el formato; no se envuelve en validación nueva ni se cambia el flujo.
