Patrón: unknown-via-in-operator-on-index-signature
Señal del verificador: : TS2322: Type 'unknown' is not assignable to type 'string'\.
Arreglo genérico: Cuando el objeto narrowed es una intersección con `MessageBase` (que lleva `[key: string]: unknown`), el operador `in` confirma la presencia de la propiedad pero no la tipa: sigue siendo `unknown` vía la firma índice. Se convierte explícitamente con `String(valor)` (mismo patrón que el caso hermano `String(msg.error)`) en vez de asumir el tipo con una aserción.
