Declare the 2.1.281 control request subtypes

and Claude OAuth requests, generate_session_title, side_question and
remote_control, but the request union did not declare them. Every
branch compared the subtype against an impossible literal and read
fields off never. The field names come from the requests the 2.1.281
executable itself sends, not from the reader.
