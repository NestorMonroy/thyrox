# T001 — Inventory existing learning capabilities

- **Estado inicial medido:** `outputs/T001-initial.txt`
- **Objetivo:** Medir qué capacidades de aprendizaje existen hoy, cuáles están cableadas en producción y cuáles faltan.
- **Archivos permitidos:** sólo el banco (`outputs/T001-*`)
- **Mecanismos reutilizados:** `git grep`, `bin/podman-execution-execute run --image` para leer versiones de Transformers dentro de una unidad
- **Invariantes:** medir, no recordar; una capacidad sin `file:line` es `missing`
- **RED:** no aplica: es un inventario; su control es que cada fila cite su archivo
- **Implementación mínima:** cuatro salidas de texto y una tabla capability | existing | production-wired | measured | missing
- **GREEN:** `outputs/T001-learning-map.txt` con la tabla completa
- **Anulación:** quitar una cita `file:line` de una fila la deja sin evidencia: el lector la rechaza
- **Criterio de cierre:** las cuatro salidas existen y cada fila cita su fuente
- **Fuera de alcance:** implementar nada
- **Evidencia:** `outputs/T001-red.log`, `-green.log`, `-annulment.log`, `-diff.txt`, `-units.jsonl`, `-telemetry.jsonl` cuando aplican
