# T002 — Record token telemetry per attempt

- **Estado inicial medido:** `outputs/T002-initial.txt`
- **Objetivo:** Cada intento del controlador lleva su uso de tokens medido, con procedencia, sin convertir lo desconocido en cero.
- **Archivos permitidos:** `src/learning/token_usage.py`, `tests/learning/test_token_usage.py`, `src/session/task_continuation.py` (sólo la fila de intento)
- **Mecanismos reutilizados:** el `result.usage` del stream-json de `thyrox -p` y el `message.usage` de su transcript (`probes/delegate.sh` ya los escribe)
- **Invariantes:** usage ausente -> `usageAvailable=false` y campos `null`; nunca 0
- **RED:** fixture sin `result` y sin transcript -> el test exige `null`; antes del código no existe el módulo
- **Implementación mínima:** `AttemptUsage` + `usage_from_stream` + `usage_from_transcript` + `attempt_usage` (resultado > transcript > no disponible)
- **GREEN:** `python3 tests/learning/test_token_usage.py` en una unidad
- **Anulación:** sustituir `None` por `0` en el caso ausente hace caer el caso `unavailable`
- **Criterio de cierre:** GREEN, anulación y `outputs/T002-token-schema.json`
- **Fuera de alcance:** precio en USD de un proveedor sin tarifa declarada
- **Evidencia:** `outputs/T002-red.log`, `-green.log`, `-annulment.log`, `-diff.txt`, `-units.jsonl`, `-telemetry.jsonl` cuando aplican
