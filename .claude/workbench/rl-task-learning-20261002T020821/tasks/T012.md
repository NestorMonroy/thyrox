# T012 — Run a real-model batch through the policy

- **Estado inicial medido:** `outputs/T012-initial.txt`
- **Objetivo:** Al menos 3 tareas reales de ingeniería, anchura >= 2, por frontera -> parallel_map -> GNU Parallel -> primitiva -> `thyrox -p` -> modelo real.
- **Archivos permitidos:** el banco (`plan.jsonl`, `probes/`), y los archivos que cada ítem declara
- **Mecanismos reutilizados:** `task_continuation run` con `--width 2` y worktrees
- **Invariantes:** Claude = 0; max_active >= 2; dueños, contenedores y cgroups distintos; uso real; verificador; recompensa; experiencia; actualización de política
- **RED:** cada ítem trae su prueba roja antes de despachar
- **Implementación mínima:** tres ítems pequeños con su `verify`
- **GREEN:** tres aceptados o bloqueados con causa, y las métricas pedidas
- **Anulación:** `--width 1` baja max_active a 1
- **Criterio de cierre:** métricas en `outputs/T012-*`
- **Fuera de alcance:** tareas grandes
- **Evidencia:** `outputs/T012-red.log`, `-green.log`, `-annulment.log`, `-diff.txt`, `-units.jsonl`, `-telemetry.jsonl` cuando aplican
