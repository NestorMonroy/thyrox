# T005 — Persist experiences in the agent store

- **Estado inicial medido:** `outputs/T005-initial.txt`
- **Objetivo:** Las experiencias se guardan y consultan en el store del proveedor, con versiones de política, recompensa y esquema.
- **Archivos permitidos:** `src/learning/experience_store.py`, `tests/learning/test_experience_store.py`
- **Mecanismos reutilizados:** el archivo SQLite de `agent_store` (nivel B, ADR-006); una tabla propia, no un archivo nuevo
- **Invariantes:** consulta por taskClass, provider, model, action, accepted, tokens, cost, latency, periodo y policyVersion
- **RED:** consulta por `accepted=True` sobre un store con dos filas devuelve una
- **Implementación mínima:** `ExperienceStore.append` y `ExperienceStore.query` con SQL parametrizado
- **GREEN:** `tests/learning/test_experience_store.py`
- **Anulación:** ignorar el filtro `policy_version` hace caer su caso
- **Criterio de cierre:** GREEN y anulación
- **Fuera de alcance:** PostgreSQL (modo compartido)
- **Evidencia:** `outputs/T005-red.log`, `-green.log`, `-annulment.log`, `-diff.txt`, `-units.jsonl`, `-telemetry.jsonl` cuando aplican
