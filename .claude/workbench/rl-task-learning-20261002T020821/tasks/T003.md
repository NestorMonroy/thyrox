# T003 — Version the experience schema

- **Estado inicial medido:** `outputs/T003-initial.txt`
- **Objetivo:** Un registro (S, A, R, S') versionado, sin secretos, que sirva al bandit, a la evaluación y al reward model.
- **Archivos permitidos:** `src/learning/experience.py`, `tests/learning/test_experience.py`
- **Mecanismos reutilizados:** `SECRET_NAME_PATTERN` de `task_continuation`
- **Invariantes:** ninguna clave ni valor con forma de secreto; versión de esquema explícita
- **RED:** una experiencia con un campo `*_TOKEN` tiene que rehusarse
- **Implementación mínima:** `Experience`, `SCHEMA_VERSION`, `to_record`/`from_record`, `assert_secret_free`
- **GREEN:** `tests/learning/test_experience.py`
- **Anulación:** retirar `assert_secret_free` hace caer el caso del secreto
- **Criterio de cierre:** GREEN y anulación
- **Fuera de alcance:** almacenamiento (T005)
- **Evidencia:** `outputs/T003-red.log`, `-green.log`, `-annulment.log`, `-diff.txt`, `-units.jsonl`, `-telemetry.jsonl` cuando aplican
