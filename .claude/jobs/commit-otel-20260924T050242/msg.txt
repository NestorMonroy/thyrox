is exported now, and nothing in production ever called
setGetEventLoggerFn, so logOTelEvent always took its "event dropped"
branch. The default now reads the real app-host state, through a lazy
require because app-host depends on this package; the setter stays
for tests. With the default back at null, exactly the six emission
cases of systemPromptTelemetry fail. Finding H-THYROX-170.

creation dates), which only the provider-internal type had.

reads modelType through a lazy getInitialSettings that keeps the old
try; behaviour is unchanged.
